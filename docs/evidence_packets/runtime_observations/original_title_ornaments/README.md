# 原版标题画面的宝珠与书：上下浮动，不跟随选项（lane R5-L6 代 R5-L5 实测）

> evidence: runtime-measured: 原版 v1.06 标题画面的宝珠与书只在竖直方向做正弦式浮动，周期约 1.65 s、上下各约 5 px，位置与鼠标停在哪一项无关; provisional: 采样只有 4–5 帧／秒，周期与振幅是拟合值 · status: record-only · tools: hsl_original_control.py, play_original.sh · updated: 2026-09-24

回答 R5-L5 转来的问题 A：原版标题画面上的宝珠（左）和书（右）会不会动、停在各选项时在哪里。重制现有的唯一原版标题帧（01/frame_001）里宝珠约在「開始新故事」文字行下方 19 px，本包说明这只是浮动途中的一个位置。

## 怎么采的

- 2026-09-24 02:36–02:46 一趟原版（Wine、cnc-ddraw 640×480），`tools/play_original.sh` 启动（开头装入的预设在收尾用 `--restore` 换回，HSL00.SAV sha1 `b90bb976` 复核；本趟没有存档）。
- 用 `tools/hsl_original_control.py move` 把鼠标停在第 1／2／3 项（第 1 项用 `click` 点亮一次；第 2、3 项用 `move`；中途一次误点进了「戰場記錄」的战场，经系统卷轴「回主選單」回到标题，没有存档），等 5 秒，再用 `screencapture -l <窗口 id>` 只截游戏窗口，每项连拍 45 张，间隔 0.15–0.26 s（每项共 7.6–9.8 s）。截图是 Retina 2×，去掉标题栏后按 2×2 平均缩回 640×480。
- 位置：取第 1 项第 1 张的宝珠块 (218,256,30,30) 与书块 (388,240,34,40) 作模板，在每张图上以 ±6 px 水平、±18 px 竖直搜索最小平均差。宝珠的位置另用绿色像素质心核对（135 张里 134 张都是 481 个像素，1 张是 456 个），两种方法结果一致。
- 原始截图与脚本在仓库外的 `ignored/l6/title/`；入库的是逐张位移表 [ornament_track.tsv](ornament_track.tsv) 与 4 格裁切图。

## 结果

停在第 1 项：浮到最高、沉到最低；停在第 2 项；停在第 3 项（原版帧见私有档案：`runtime_observations/original_title_ornaments/title-ornaments-4-states.png`）

| --- | --- | --- |
| 水平位移 | 135 张全为 0 | 135 张全为 0 |
| 竖直范围（相对模板帧） | 0 … +10 px | −2 … +8 px |

| 640×480 画面上的位置 | 质心 x＝233，y 在 270 与 280 之间往返（球体约 26×26 px） | 书约占 (375,245)–(424,286)（模板帧），整体在其上 2 px 到下 8 px 之间往返 |

- **会动**：两件都只做上下浮动，形状接近正弦；三组采样的间隔各不相同，拟合出同一个周期，说明 1.65 s 不是采样混叠造成的。
- **不跟随选项**：停在哪一项，两件的平均位置差不超过 0.3 px。选中的那一项只是文字变金色并出现火花（第 1 项的火花见第 1、2 格）。
- 三个文字行（黑色描边的竖直范围）：第 1 项 y 243–261，第 2 项 286–303，第 3 项 331–348。宝珠中心因此总在第 1 项文字中心（y≈252）下方 18–28 px，落在第 1、2 项之间；01/frame_001 的"约 19 px"对应浮到最高点附近。
- 两件的相位差在三组之间不一致（48°、194°、193°；三组相隔几分钟）：两个周期可能只有很小的差别，也可能各自独立计时，本次采样分辨不出，不要据此实现"同步"或"反相"。

## 边界

- 采样率只有 4–5 帧／秒，不是逐帧；周期、振幅与"正弦形"都是拟合结果。若要逐帧时序，需改用 `hsl_win32_memread.exe --repeat` 找浮动的计数器（ScreenCaptureKit 录原版窗口只得到最初约 0.9 s，见 [tools/README](../../../../tools/README.md)）。
- 书的范围由目测裁切图得到（颜色和旁边的雕像接近，无法用阈值分割），误差约 ±2 px。
- 没有看鼠标不在任何选项上的情况，也没有看从一项换到另一项时是否有过渡动画。
