## 来源、范围与可玩合同

| 装备 | 来源效果与当前接入 |
| --- | --- |
| 冥晦之輪232 | 移动后仍可施放自身拥有且当前合法的魔法 |
| 奧義之證233 | 普通攻击／反击范围提升一个源索引 |
| 穹蒼之鍊236 | 同时具有上述两种能力，并增加1移动力 |

同一布尔效果多个来源按OR计算；两个范围饰品不会增加两档。add_move仍是独立数值累加。所有装卸保留源职业资格、六槽／八格库存、不能卸武器和已接受的位置规则；不把三件装备放进默认库存。

RANGE.H给出普通索引1／2／3；当前源武器只使用1／2，范围加成可以进入3。RANGE.TXT中的这三种是四向十字，分别4／8／12格，不是曼哈顿半径的菱形，也不包含自身格。源射击／方向／大型专用矩阵仍未开放。法术与绝技继续读取自己的源range和effect_range。

`PositionCapabilityRules`仅从当前装备与角色声明计算结果，不保存第二套能力状态。`BattlePlayLoop`的命令资格、法术选择和最终确认都核对当前行动是否已移动；`SkillResolutionRules`在接受移动施法提案前核对其新站位。取消选目标仍处于移动后阶段，只有取消待提交移动回到原点才恢复未移动资格。换装免费，可以在移动后获得或失去施法资格；不会增加新的移动预算或撤销已接受位置。

白光之翼保留两个独立行动。第一次只移动／待机后，第二次允许在新位置原地施法，即使没有移动施法装备；第二次再次移动，则重新需要当前移动施法能力。双击只增加普通系列中的打击，不重置行动阶段、不授予施法或额外队列槽。毒／禁魔时间与资源尾部依然只在最后行动结束处理；每次有效攻法援的EXP与资源支付独立结算。

AI有权限时遍历当前合法移动施法格；无权限时只尝试原地施法。进攻无法在当前格执行时，已有全图追击仍可先走到未来施法位置，然后在下一独立行动重新决策。友军治疗／驱毒遵守同一资格，用药保持自己的相邻移动规则。目标死亡、当前能力被移除、MP耗尽、禁魔或路径失效不能使旧候选继续支付／移动；普通攻击、物品和等待保持既有合法回退顺序。

本作UI在移动预览明确提示“移動後不能施法；取消可返回原位”，移动后菜单隐藏不合法的魔法入口；装备预览显示资格和范围变化。禁魔／MP不足仍沿既有可读性策略保留禁用的技能列表，**不声称这个禁用列表等同原作隐藏菜单**。原地图、镜头、攻击／法术动画与声音复用，预告和反击读取当前同一范围；没有新增效果专属音效或原时钟声明。
