# 玩家指南

## 开始

准备好正版数据后，照 [README「运行」](../README.md#运行)里的命令开游戏。第一次启动会先从原版数据生成游戏文件，要等十分钟左右，之后直接进标题。Windows 和 Linux 的入口见 [CONTRIBUTING §6](../CONTRIBUTING.md#6-windows-与-linux)。想跳过标题直接看某一关，用 [PLAYTEST](PLAYTEST.md) 里的试玩存档。

## 操作

和原版一样以鼠标为主：左键选择、确认，右键取消。开场动画按任意键跳过。对白用左键、Enter 或空格翻页。菜单也能用方向键或 WASD 移动，Enter、空格或 Z 确认。

战斗里：

- 鼠标移到画面边缘或按方向键卷动地图，按住 Shift 卷得快一倍，这是原版就有的。
- 刚轮到你、还没下命令时，Esc 或右键打开系统卷轴：任務說明、存读戰場記錄、讀取回憶錄、設定選項、回主選單。其他时候 Esc 和右键都是取消。
- Home 把镜头拉回当前角色，重制新加。
- F5 存、F9 读这一场的戰場記錄，和系统卷轴里存的是同一份，重制新加的快捷键。演出或操作进行到一半时不能存，会提示稍等。
- 技能列表用 ↑↓ 和 PgUp／PgDn 翻页，不支持滚轮。

大地图上 Esc 或右键打开系统卷轴，可以整理裝備、存读回憶錄。任何画面按 Tab 打开「重製選項」，游戏随之暂停，再按 Tab、Esc 或右键关上；也可以从 設定選項 › 重製選項 进去。

用 `tools/play.sh` 启动时，P 和 N 是开发用的停格键：P 冻住整个游戏，N 往前走一帧，再按 P 继续，左上角会写「停格中」。不想要它就设 `HSL_DEBUG_PAUSE=0` 再启动。

### 触屏

手机、平板浏览器和触屏笔记本可以只用手指玩，这是重制新加的，原版只有键鼠。没有触摸屏的电脑完全不受影响，触屏笔记本上鼠标照常可用。

- 一指点按等于左键点击，在抬手那一刻生效；按住不动一小会儿或按住拖动，等于按住左键拖。
- 两指轻点等于右键：取消，或在战斗里打开系统卷轴，和 Esc、右键一样。
- 两指按住一起移动就拖动战斗地图和大地图，松手即停。像抓着地图拖：手指往左，地图跟着往左。
- 两指的手势不会点到手指下面的单位或格子。

## 存档

存档放在 Godot 的用户数据目录 `HSL Remake` 下：macOS 是 `~/Library/Application Support/Godot/app_userdata/HSL Remake/`，Windows 是 `%APPDATA%\Godot\app_userdata\HSL Remake\`，Linux 是 `~/.local/share/godot/app_userdata/HSL Remake/`。

- **回憶錄**：8 格，在大地图的系统卷轴里存，标题画面的书里读。
- **戰場記錄**：每场战斗一份，只记这一场打到哪里。
- **战役进度**：每次过场自动记下，标题画面的「戰場記錄」从这里接着玩。

戰場記錄的格式换代后，旧格式的不再读取，读档时会提示未完成；关卡或规则版本对不上的也不读。

## 重製選項

默认全部照原版。页首有三个预设：「原版」全部照原版；「舒適」打开宝箱显示、战斗信息、操作提示、合并升级加点、快速演出、败北重来和对白断行保护，光标和字体仍用原版；改任何一行就成了「自定」。选项不进存档，随时可改，每项的原版行为和改良理由见 [OPTIONS](OPTIONS.md)。

## 已知的坑

- Windows 的启动脚本还没在真机上跑过，遇到问题请附上 `python tools\hsl.py doctor` 的输出。
- 机器人能打赢一关，不代表玩家也能过，更不代表难度和原版一样；整章还在等人从标题完整玩一遍。
- 与原版已知的不同之处都登记在[差异清单](evidence_packets/static_reverse/parity_gap_inventory.md)，报告问题前可以先查一下。
