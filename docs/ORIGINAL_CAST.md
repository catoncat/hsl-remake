# 《幻世錄》原作有名角色名录

写外传、续集时查人用。只收有名字的角色；小兵、店员、无名村民不收（附录列了几个有固定称呼但没有名字的）。

口径：
- 场景写「场景名（LEVEL0xx）」，对照 [BATTLE_NAMES](BATTLE_NAMES.md)；引文出自内部的台词全本 `docs/internal/ORIGINAL_SCRIPT.md`（不随公开导出），剧情归纳见[原作剧情简报](ORIGINAL_STORY.md)。
- 结局一＝妖精王线，结局二＝席德爾线，结局三＝接觸线。三条都接同一段尾聲：雷歐納德下落不明，緹娜留在拉爾斯，漢克斯陪在旁边。
- 结局不是二选一：塔克斯之死后按三条结局的累计分数从高到低，取第一条条件成立的。所以放走席德爾不一定进结局二，古代神殿遺跡里的合体也不一定进结局三。
- 职业写 PLAYERS.TXT 的 job／class，括号里是游戏里显示的职业名。四维是模板的 str／dex／mind／con。
- HP 写重制战斗数据里的出生值（content/battles/battle_NNN.json，模板等级、未计进场上调），只作量级参考。
- 等级：原版没有写死的出场等级。单位出生（进场后第一帧）时调级一次（[原版自动调级](evidence_packets/static_reverse/original_auto_growth.md)）：先按四维总和推基础等级 `1 + ceil((总和-52)/5)`；敌人再按我方平均等级、PLAYERS 的 level_adjust_range（范围）和 level_adjust_disp_range（离散）随机上调，只升不降；队员入队不上调，就是基础等级。表里写「L27 起，最高约 L73」的意思是：基础 27 级，我方越强它越高，公式上限是基础＋范围＋离散。

## 续集可用的人物与悬念

1. **漢克斯**：尾聲里唯一确定和緹娜在一起的人；和雷那笔「皇帝陛下的仇」还没算。
2. **琥**：尾聲没交代他的去向。他和雷是「少了我，你這死神就只剩一個頭了」的搭档，可以写成一直在找雷，或一直和雷在一起。
3. **克羅蒂**：三条结局都活着；塔克斯死了，理想破灭，「新的開始」没有下文；她熟悉魔騎士團内部，魔騎士團残部续集可用作敌人。
4. **雷特**：「下一個惡魔就是你」这句预言没有收尾，黑翼之子的线可以直接接上。
5. **雪拉**：三条结局都活着；亞雷比斯長老说的「禁忌的力量」和父亲的遗愿都能延续，妖精寿命长，时间跨度不成问题。
6. **嚎**：要让世人知道真相，可尾聲之后真相公开了没有、冀羅与那可那魯的暗藏兵力去了哪里，原作都没写。
7. **克里夫**：走艾瓦台地路线他活着，薛維斯港商人，对雪拉脸红过，适合做商店或客串。
8. **布萊特与魔神残骸**（只作传说，不作出场人物）：六英雄的领导者、聖劍的原主、妖精王念到的名字；加上「魔神不止一个」的暗示，是续集可用的悬念。
