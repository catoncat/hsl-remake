# Content Layers

- `battles/`: live Godot scenario configuration. `first_battle.json` is the current product contract.
- `imported/`: reusable data/assets derived from the original resources, with provenance and unresolved boundaries.
- `generated/`: compact reproducible facts generated by parsers or static analysis.

Raw original files, temporary extraction trees, screenshots, videos, and long analysis output are not content inputs. They remain in the Wine prefix, an external archive, or temporary `ignored/` output.
